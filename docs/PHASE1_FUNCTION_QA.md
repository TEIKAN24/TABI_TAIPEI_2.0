# 第一階段｜功能測試結果（2026-11-09）

## 測試環境

本機 Chromium，透過 Playwright 載入原始 HTML/CSS/JavaScript，CSV/JSON 用本機同名資料回應。測試視窗 393 × 852，另檢查 320 和 430 CSS px。不是 GitHub Pages 站台實測，也不是 iPhone Safari。

## 已實測通過

- 首頁七個 HTML 章節入口切換到對應 `#view/<chapter>`；其他章節不會意外顯示旅支度的新面板。
- 右側選單由右邊進場，開啟完成後 `x=93px`、寬 `300px`；漢堡圖示固定位置。側選單原生連結功能正常。
- 旅支度七組 `<details>` 可開合；切換項目時前一項自動收合；箭頭以 CSS 中心旋轉。
- Notes、TWAC、Pass 三個分頁正常切換，原 TWAC、FunPASS、Taiwan PASS 以及 TR-PASS 官方連結均存在，第三項移到首屏外但可捲動取得。
- 各種螢幕寬度下沒有文件水平溢出，測試頁未拋 JavaScript 例外。
- イベント：11 個月份卡與 85 筆清單 DOM 可生成；點選月份後捲動月份軸位置有改變。
- 夜市地圖：使用原始資料產生 32 個標記、27 條 SVG 交通線；393px 下 359 × 618px。
- 街歩き地圖：用**網站實際的切換按鈕**切至エリア再切回夜市，原本同一張地圖維持 359 × 618px，不需重建資料。
- 遠出：10 個路線時間軸仍存在；點擊目的地後至少一個可見時間軸的 `data-daytrip-played` 變成 `true`；返回其他頁後會重置播放狀態。
- `data/`、`food/`、原 `js/*.js` 的既有功能檔與使用者穩定 ZIP 的 SHA-256 相同。

## 需要在手機或正式測試站驗證

- iPhone Safari 的 393px 字形與行距，Safe Area、地址列收合、加入主畫面後的顯示。
- 80px `backdrop-filter` 模糊在 iPhone 上的流暢度、低效能手機與減少動態效果。
- GPS 許可、實際步行距離、外部 Google Maps／網站連結是否能在網路環境開啟。
- Service Worker 的安裝、離線資料更新與瀏覽器快取完整性。
- 所有夜市與街歩き圖層的觸控縮放／慣性滑動；イベント資料的最新性。
- Figma 特殊外框字 SVG 尚未取得，不可稱全站 Pixel-perfect 驗收完成。

## 一項特殊測試差異

原 v1.2 的一個強制開啟測試同時打開兩個互斥地圖 `<details>`，其中一個隱藏地圖容器寬度會是 0px。這個數字**不能當成正常操作失敗**。以 UI 按鈕進行夜市／街歩き切換，地圖有實際尺寸且回到夜市正常。
