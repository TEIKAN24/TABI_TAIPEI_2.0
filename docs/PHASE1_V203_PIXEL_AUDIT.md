## 尚未驗收／刻意不改

1. **逐像素 PNG 疊圖差異數值**：Figma 的短效 screenshot URL 無法直接下載至本地容器；本輪使用 Figma 圖層座標與本機 Chromium DOM/SVG 盒子量測，不能宣稱完整 Pixel-perfect PNG 驗收。
2. **標題以外的日文字體**：例如 Figma 的 `A P-SK IshiiMincho Old StdN`（數字）、`A P-OTF Kasumi Seiran Min2`（內頁小標），目前環境仍沒有授權 Web Font。沿用系統備援，不擅自更換 Figma 字體設計；不重新發佈任何 font file。
3. **完整地圖生命週期與 iOS Safari**：當某個地圖所屬章節隱藏時，其容器寬度可能回報 0。需到 GitHub Pages 的 iPhone Safari 上測試切回原章節後的重算、滑動與線動畫。
4. **其他 Figma Frame**：觀光、散策、體驗、遠出等全內頁的視覺逐頁校正仍屬下一階段；搜尋器及空港アクセス未重新設計。
