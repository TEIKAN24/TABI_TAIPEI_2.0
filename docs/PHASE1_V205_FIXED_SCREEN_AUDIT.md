## 實際程式／瀏覽器回歸檢查

在本機 Chromium 模擬瀏覽器進行，測試寬度 **320、393、430 px** 與 **393px 模擬 iOS Safari UA**：

- 首頁根文件 `scrollHeight=852px`，手動嘗試 `window.scrollTo(0,500)` 後 `scrollY=0`；章節同樣沒有整頁捲動。
- 旅支度清單較長時，**清單內部**實際 `scrollTop=43px`（393px 情境），文件保持 `scrollY=0`；七項收合、TWAC 與交通票證分頁正常。
- 散策／夜市原始地圖在 393px 顯示區為 **x=16、y=189、w≈361、h=607px**（Figma 設計框約 x16～379、y189～797）。320px 時寬≈288px，430px 時寬≈398px。
- 載入原始夜市地圖資料／捷運資料後，SVG 地圖有路徑及標記分群；商圏地圖也繪出原始 SVG 路徑與 32 個初始地圖標記。**未使用假資料、Figma 全畫面截圖或替代地圖。**
- 観光可切換攝影景點、活動分頁；原本的 イベント 月份切換／活動清單可正常更新。
- 此輪瀏覽器測試 `pageerror` 數量為 0；所有 134 個網站檔案（含新增檔）中的 `data/`、`food/`、`assets/` 檔案位元組與 v2.0.4 相同。

## 這輪**未**通過／尚未驗證

1. 目前提供的是本機 Chromium 加 Safari UA 模擬，**不是 iPhone 實機 Safari**。動態工具列、安全區及 PWA 模式需要在 GitHub Pages 部署後實測。
2. 散策 Figma 初始地圖的縮放與標記位置仍可能與原始互動地圖不同；先保留功能邏輯，不以靜態圖片替換。後續需校正地圖初始視角和控制項樣式。
3. 観光清單的每張卡片、標籤、列表行距與 Figma 尚未逐項完成像素差異檢查；這輪只完成固定的章節／分頁骨架和真實內容區。
4. 尚未完成 Figma 定稿的搜尋器和空港アクセス仍使用原始程式與原有外觀，未提供新版設計。
5. 味わい、体験、おみやげ、遠出等尚未逐頁完整重構，仍採固定外框 + **內容容器自身捲動**的過渡相容方式。原生路線生長效果、外部 GPS 定位在實機仍須單獨驗收。
6. 缺少的商用日文字體仍未擅自替換或發佈，特殊字形沿用使用者提供的原始 SVG 外框。
