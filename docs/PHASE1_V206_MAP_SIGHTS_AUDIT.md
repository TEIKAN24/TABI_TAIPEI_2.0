## 回歸測試

測試使用本機 Chromium 的 320、393、430px 模擬瀏覽器與**原始本機資料檔**，不存在展示用替代資料。

- 外層文件 `scrollHeight=852`，沒有水平溢出；博物館列表本身可捲動。
- `data/sights.json` 博物館類六筆已載入，第一筆的 Google Maps 外部連結不變；原始 `data/`、`food/`、`assets/` 87 個檔案與 v2.0.5 **位元組完全相同**。
- 博物館第二層分類按鈕可以切換，観光主分類可以開啟イベント。
- 夜市地圖使用原始路線／行政區向量資料，顯示至少 27 個底圖 SVG path、互動標記；點擊「士林夜市」能顯示原始詳情，按返回回到地圖。
- 商圏頁可以開啟原始另一套互動地圖。
- 旅支度七個收合標題仍存在；各測試寬度沒有 JavaScript uncaught pageerror。
- 本輪未變更其他既有核心資料庫、搜尋器、空港アクセス或路線動畫。

## 尚未完成／不得宣稱通過

1. Figma 的地圖標記視覺避讓位置仍與資料驅動地圖不同，特別是公館／師大兩處動態聚合狀態；**不能宣稱地圖標記逐像素一致**。後續需在保留原有縮放／GPS 群集規則前提下獨立校正。
2. Figma 部分小字商用字體在執行環境缺少對應網頁字體授權。首頁特殊標題已使用使用者提供的 SVG 外框；本次博物館文字仍使用系統／網站現有日文字體，因此字形無法保證完全一致。
3. 原始資料在第四張及之後仍有額外標籤。Figma 首屏未顯示的資訊仍完整保留，初始可視畫面與原稿有少量差異。
4. イベント月份切換、真實 GPS 權限流程、iPhone Safari 動態工具列／PWA 與各外部連結的遠端可用性，**本輪未完成實機驗收**。本機能開啟事件資料並不等於已通過所有互動。
5. 本輪僅精修 `散策/夜市` 與 `観光/博物館` 初始畫面。其他 Figma 畫面尚未逐張完成校正。
