## 回歸測試

原始本機資料以離線嵌入方式提供給 Chromium（不是假資料），測試 320、393、430px，記錄：

- 全畫面文件高度 852px；清單本身可捲動，沒有新增整頁長捲動。
- 14 筆 `映えスポット`、13 筆 `ロケ地・聖地巡礼` 均載入，切換及 ARIA 選取狀態正確。前四筆 Google Maps 連結保持原始 URL。
- イベント月曆載入 85 筆活動列，熱度格狀畫面可以由鍵盤切換至下一月份。
- 夜市地圖含 27 個以上基底 SVG path；393px 初始狀態公館與師大可各自點擊、開啟既有詳情並返回。另一次拖曳測試後，地圖視角實際改變且標記重新聚合。
- 夜市／商圏原有兩種地圖仍載入，所有寬度本輪沒有未捕捉的 JavaScript 錯誤。
- `data/`、`food/`、`assets/` 共 **87 個原始檔案與 v2.0.6 的 SHA-256 完全相同**；未刪除任何檔案。

## 尚未完成（不可宣稱 Pixel-perfect）

- 原有地圖在其他縮放範圍仍會依資料動態分組，不能使所有標記位置與 Figma 靜態示意完全相同；此項是保留可操作地圖功能的必要取捨。
- 撮影スポット Figma 首屏未顯示的其他 `台北101` 等原始標籤依資料保留，且未逐一校正其字形及第四張之後的卡片。另一個攝影子分類（ロケ地・聖地巡礼）仍使用既有樣式。
- イベント的日期格狀圖已對應，但下面的統計與活動列之垂直間距仍與 Figma 存在差異。Figma 示意中的活動數量不會覆蓋真實活動資料統計。
- 本機 Chromium 不允許直接瀏覽 HTTP localhost（`ERR_BLOCKED_BY_ADMINISTRATOR`），因此本輪沒有完成直接由 HTTP 網址載入的第二輪驗證；測試採用與 v2.0.6 相同的原始檔案內嵌方式。
- 實際 iPhone Safari、GPS 權限、PWA 安裝後的工具列高度與外部網站遠端可用性仍需在 GitHub Pages 部署後確認。
- 商用日文字體仍未取得授權 Web Font，特殊外框繼續使用原始 SVG；本輪沒有修改 Figma 字體或造型。
