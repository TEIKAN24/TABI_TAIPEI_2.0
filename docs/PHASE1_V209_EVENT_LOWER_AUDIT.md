# TAIPEI CITY GUIDE 2.0｜v2.0.9 イベント下半部精準校正

日期：2026-11-09。工程基礎：v2.0.8 完整版；視覺依據：本次使用者上傳 `4-3-1.png/svg`、`4-3-2.png/svg`、`4-3-3.png/svg`。原版月曆的版型、週別長條與熱度格狀圖及其資料／月份操作均不重寫。

## 修改範圍

1. **月曆以下固定排版**：統計月份文字在 Y=346px、總數約 Y=361px，條件泡泡 Y=362px，活動清單從 Y=390px 開始；月份切換、選日期或篩選資料，不會推動整個統計區和清單。
2. **條件入口**：右側新增真實 HTML 按鈕「条件を指定 ＋」，393px 基準尺寸 72×18px、X=307、Y=362px；點擊後呼叫**原本**的條件面板，沿用原有城市／類型資料及篩選程式。點選條件後面板收合，變成可逐一取消的泡泡，無需改動核心 events.js。
3. **條件泡泡**：取消舊版的額外 24px 佔位高度；所有條件泡泡在統計行右側排列，細框 1px、小字 8px、圓角約 9px。日期／城市／類型篩選仍可移除，活動筆數仍為動態統計。
4. **頂部漸層**：根據使用者附上的 SVG，只提取由 Y=390px 開始的三個漸層**裝飾路徑**，製作本機 `assets/figma/event-list-glow-v209.svg`。並未把整張 Figma 畫面當成圖片；活動文字、條件控制與卡片都維持真實 HTML/CSS/JS。
5. **卡片節奏**：維持此前已校正的 96／85／82px 卡片列高，以及標題約 X=118px、分隔線約 Y=486／571／653px，不任意改寫清單排序與標籤內容。對應圖片是設計示意；網頁繼續呈現真實活動名稱與日期，故文案長度可能不同。
6. **Safari 相容性**：取消隱藏容器的程式化捲動，避免切換已選日期與條件時整塊月曆／列表被自動向上捲動。唯有活動清單本身可以獨立捲動。
7. **離線快取**：Service Worker 版本更新為 v2.0.9，並加入新增 CSS／JS／裝飾 SVG。

## 功能回歸

- 320、393、430px 模擬畫面下，完整頁面高度仍為 852px，清單可在內部捲動；沒有捕捉到 JavaScript 例外。
- 初次載入仍是原版週別長條；原始熱度圖可以切換，月份可以切換；活動數量隨原始資料改變，不固定寫死。
- 新條件入口可開啟原本的城市／種類篩選；選擇城市後生成條件泡泡，點擊 × 可移除；條件變動未改變統計與清單 Y 座標。
- 選取日期並加選城市時，兩個泡泡同一行排列，月曆以下保持固定；日期與城市／種類的實際篩選程式碼仍為原本 `js/events.js`。
- 観光另外 14 筆攝影景點資料仍可切換顯示；沒有修改原始地圖、GPS、推薦器或資料庫的邏輯。
- 相較 v2.0.8：`data/`、`food/` 及原本全部 `assets/` 下的 **87 個檔案 SHA-256 均相同，原始 `js/events.js` 和 `css/events.css` 也相同；無原始檔刪除。

## 已知差異／未完成

- 使用者提供的三張 Figma 畫面為熱度圖示例，但依照上一輪明確要求，**月曆繼續維持原版長條圖預設畫面**，只改月曆以下；因此整張畫面與示例的月曆內容不會一致。
- 真實事件名稱、月份筆數、日期、狀態與示例文案不同，不應以假資料填補，亦不能宣稱所有文字逐像素一致。
- 現有商用字體並未新增 Web Font 授權，手機日文字形光柵化可能與 Figma 輕微不同。
- iPhone Safari／PWA 實機的長按選日、選條件後泡泡可點性與平滑捲動仍需上線後測試；本輪為 Chromium 行動模擬，沒有實機驗證。
- 這次沒有對夜市地圖、路線圖及 GPS 重新進行完整端對端驗收；它們的程式與資料未動。
