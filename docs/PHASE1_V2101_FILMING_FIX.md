# TABI TAIPEI 2.0 — v2.0.10.1 ロケ地・聖地巡礼 修正

## 問題分析

v2.0.9 的ロケ地・聖地巡礼仍沿用舊版 74.8px 密集列表與左側編號，統計固定「掲載 14件」。v2.0.10 已將其改為 123.4px 卡片並更新成「掲載 13件」，但原有攝影卡片的樣式與新卡片非常接近，且之前未對此分類單獨校正位置；實際線上畫面是否已讀到新 CSS/JS，尚無使用者部署頁面的證據。

## 修正

- 對照 Figma 4-2 已確認的通用攝影卡片位置，校正ロケ地・聖地巡礼標題與藝術家標籤的左側位置與垂直間距。
- 強制提升 CSS、JS 版本查詢參數至 `2.0.10.1`，更新 service worker CACHE，讓更新後線上裝置可取得新資源。
- 原始資料庫及所有 Google Maps 鏈結不變，13 個地點名稱、原藝人標籤維持 HTML 文本可點擊。
- Figma 沒有單獨完成此子分類的卡片稿，故沿用 Figma 4-2 既有卡片系統；沒有杜撰副標。

## 部署注意

把更新 ZIP 解壓、以原目錄階層覆蓋 v2.0.10 的測試專案。GitHub Pages 更新後，重新整理頁面；若是加入主畫面的 Web App，請關閉並重新開啟。新版本顯示「掲載 13件」、沒有左側編號、卡片間距約 123px。如仍顯示舊版，檢查 GitHub Pages 是否成功部署及離線快取。

## 本機回歸結果（2026-11-09）

- 320、393、430 CSS px 測試：六個観光子分類中所驗證的博物館／アート／歴史文化／人気観光地，以及映えスポット、ロケ地・聖地巡礼維持可操作；本輪沒有 JavaScript pageerror。
- ロケ地・聖地巡礼共有 13 張真實資料卡片，13 個地圖連結，固定容器高度 852 px。檢查原版イベント月曆仍以長條圖為初始模式，月份能切換。
- 393px 測得第一張ロケ地卡片：標題 (x≈26.88, y=298.00)、藝人標籤 (x≈26.88, y=357.00)、卡片高度 123.39px；採用 Figma 4-2 共通攝影卡片座標，而非宣稱此子分類有獨立成稿。
- 不能確認你已部署的 GitHub Pages 倉庫是否使用新檔案；若線上仍有左側 01/02 編號，請檢查上傳與快取／重新整理。
