## 內容與互動

- 「アート・デザイン」7 筆：前四張卡片依照設計上的日文標題和繁體中文副標文字排版，保留原始 Google Maps 目標；已有官網的卡片仍使用原始外部網址，UI 顯示「公式へ」。標籤仍從原資料庫生成；第 2 張卡片的兩個標籤依原稿呈現順序。
- 「歴史文化」14 筆與「人気観光地」8 筆：採用同一個 123.4px 高度的清單卡片、外框標籤與內部捲動，但**這兩類在 Figma 尚無獨立完成的畫面**，故不憑空編寫日文譯名或副標。
- 「ロケ地・聖地巡礼」13 筆：從原始 data/sights.json 讀取地點和演出者／MV 標籤，沿用既有攝影景點的卡片樣式；修正上方總數由「14 件」固定值變為依實際選中分類更新 13／14 件。
- 不改資料庫、現有連結、分類控制器、事件日曆或路線／GPS 程式；不使用整頁圖片。

## 功能回歸測試

- 320／393／430px 下，博物館 6、アート・デザイン 7、歴史文化 14、人気観光地 8、ロケ地・聖地巡礼 13、映えスポット 14 筆皆保持原始資料數量，外部 Google Maps 連結仍可點擊。
- 上述分類均能切換，根文件不會水平或垂直溢出，清單有自己可捲動的區域。
- 攝影兩個子分類切換時總數能改為 13 與 14；イベント月曆仍預設原版長條圖，月份切換正常。
- 三種寬度均未捕捉到 JavaScript 頁面錯誤。測試為資料／資產內嵌的本地 Chromium 手機模擬，不代表已在 GitHub Pages 或 iPhone Safari 完整驗收。

## 尚未驗收或待改善

1. 歴史文化、人気観光地、ロケ地・聖地巡礼尚無獨立 Figma 成品，因此只套用已確認的共通元件規則，**不宣稱逐像素一致**。
2. 各裝置商用日文字體可用性可能不同；本版沒有加入受限字體。
3. 官網連結、GPS、地圖長距離拖曳與 iPhone Safari／PWA 尚未在真實網路環境端對端測試；只確認其原始程式與連結未被修改。
4. イベント／旅支度／其他頁面並非本輪修改範圍；原版另有未完成的細部差異。
