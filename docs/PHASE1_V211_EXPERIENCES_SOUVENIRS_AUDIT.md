## 待驗證與可見差異

1. iPhone Safari 實機、GitHub Pages 部署、離線 Service Worker 更新及直接從網址進入子頁，**仍需實機驗證**。
2. Figma 5-1 的第三張變身體驗店名與 JSON 原名不同；這版保留 JSON 原名，以避免不經確認改寫內容。
3. Figma 7-1 以重複示意文字表示卡片，本版使用各筆真正商品／商家名稱與標籤；沒有來源的描述副標不填假文字，因此部分卡片留白與示意圖不同。
4. 只有首屏及共用列結構做了像素位置校正，尚未完成整個章節逐像素疊圖誤差量化；這版不宣稱全章 Pixel-perfect。
5. 深色模式做視覺比較；其他外觀模式仍由原網站控制，需另外驗證。
