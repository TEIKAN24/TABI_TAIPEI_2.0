# TAIPEI CITY GUIDE 2.0 — v2.0.12 橫向無限分類轉盤

## 設計決定

採用使用者確認的 A / A / A：

- **真正無限循環**，末項接回首項，沒有硬性終點。
- **選項吸附完成後才切換下方內容**；拖曳與慣性移動期間不重新建立清單。
- **中央一個完整字串，左右露出鄰居**；保持原始日文文字與固定字級規則，不對長分類名稱縮放。
- 白色短線固定在分類列中央 `left:50%`，高 10px，寬 1px，和文字位移分離。
- 視覺中心項白色、13.2px、600 字重，其餘灰色、12px、400 字重。
- 第四個尚未指定的偏好沿用上輪推薦預設：**點擊左右鄰項亦會吸附並切換**；可再關閉。

## 此次修改範圍

僅套用至：

1. 04 観光 → 名所・博物館 → 4 個下層分類。
2. 05 体験 → 4 個原始分類。
3. 07 おみやげ → 4 個原始分類。

未修改撮影スポット、散策、遠出、イベント、搜尋器及空港アクセス的分類方式。

新增 `js/infinite-category-wheel.js`、`css/infinite-category-wheel.css`，由兩者描繪**真正可觸控的 HTML/CSS 轉盤**，非 Figma 整張圖片或輪播截圖。原始按鈕仍在 DOM 裡並保留原始資料 ID、`aria-controls`、面板、JSON 與外部連結。當轉盤吸附完成，才觸發原有按鈕的 `.click()` 以執行資料切換與計數更新。

對 `js/guide.js` 只新增一個手勢排除判斷：新轉盤的水平滑動不能被原料理搜尋抽屜攔截；其他舊邏輯保持原樣。

## 物理與呈現

- 指標拖曳：使用 `PointerEvent` 追蹤位移及速度。
- 放手慣性：初速上限 3.7 px/ms、阻力 `exp(-dt/265)`，最後使用 ease-out 三次方吸附最近的文字中心。
- 選項在世界座標中以原始字串實際量得的寬度 + 25px 間隔排列，環狀複製為 9 個輪回顯示片段，必要時重置內部座標以避免無限數值增長。
- 使用者偏好的減少動態效果開啟時，會略過慣性並快速吸附。
- 支援觸控甩動、滑鼠拖曳、觸控板橫向滾輪、左右鍵與點擊旁邊選項。
- 網頁本身仍固定，清單仍只在內部捲動。

## 驗證結果

本機使用原始 HTML、CSS、JavaScript、JSON，瀏覽器採受控資料回應，**不是 iPhone Safari 實機或真實 GitHub Pages HTTP 端對端測試**。

- 320 / 393 / 430 CSS px：三個轉盤均已載入；中心短線位置對齊可視中線；各往右按一次後，資料面板正常切換並且原始列表筆數正確：観光→アート・デザイン 7 筆、体験→台湾シャンプー・マッサージ 5 筆、おみやげ→雑貨・小物 13 筆。
- 393 px 觸控模擬：三個轉盤快速左甩後均可繼續依慣性移動、吸附，甩動期間下方資料維持原分類；放手吸附後更新，原料理搜尋抽屜未誤開。
- 320 px 測試連續 5 次鍵盤右移：三個分類均在最後一項後回到第一項，再次選擇下一項；沒有超出資料庫索引或出現 JS 例外。
- 整個 `body` 高度不會超出 852px，可滑動的內容仍是內部清單。
- `data/`、`food/` 內共 15 個資料檔案與前版 SHA-256 一致。原始 159 個檔案均保留、無刪除。
